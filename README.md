# Dlcounter version 1.1.0

Dlcounter is a simple download counter for CMSimple_XH.

Dlcounter is a GitHub fork and an update of the Dlcounter_xh plugin v.1.0.

It requires CMSimple_XH ≥ 1.7.0 and PHP ≥ 7.1.0.
Dlcounter also requires [Plib_XH](https://github.com/cmb69/plib_xh) ≥ 1.2;

## Requirements

Download the ZIP file
Unzip it
Rename the main folder from “dlcounter-master” to ‘dlcounter’
Copy “dlcounter” to the ./plugins/ folder

The Rest of the Installation and operating requirements for this plugin are the same as those described in README_XH.md
